CNN Malaria Detection



A Convolutional Neural Network (CNN) that classifies blood cell images as Parasitized (malaria-infected) or Uninfected.



Overview



Malaria is a life-threatening disease caused by parasites transmitted through the bites of infected female Anopheles mosquitoes. Early and accurate detection is critical for effective treatment. This project uses deep learning to automatically detect malaria parasites in microscopic blood smear images.



\- Task: Binary image classification

\- Classes: Parasitized / Uninfected

\- Framework: TensorFlow / Keras

\- Status: In progress
